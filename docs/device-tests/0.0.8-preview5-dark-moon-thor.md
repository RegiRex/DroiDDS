The source summary describes the SVC remainder as outside rendering work. The
actual counter is narrower: `gpu.busy` measures only `process_command_list`.
Standalone display/texture transfers, fills, DMA and GPU synchronization may run
inside SVC handling without contributing to that timer. Thus **33.974630 seconds
is not proven non-rendering time or pure SVC dispatch/kernel overhead**. Source
inspection identifies candidate paths; the current report does not assign their
individual costs.

The non-overlapping accounting partitions total core wall time into CPU shader
**32.34%**, input decoding **9.90%**, placement **7.50%**, remaining command-list
work **8.55%**, scanout **1.26%**, SVC work outside the command-list timer
**33.68%**, frame/audio work **0.052%**, and the unclassified remainder **6.72%**.
These scopes measure elapsed host time, not hardware utilization. Audio-event
time includes peripheral ticks as well as DSP activity.
