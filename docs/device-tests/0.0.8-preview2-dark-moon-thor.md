- `compiler_failures=0` covers a different path and does not negate those driver

- The 44,320 guest PCM frames were all silent. Four underruns in this early

The existing error string does not identify whether the rejecting pipeline used
the generic interpreted vertex shader, a translated shader or placed vertices,
nor its complete static/specialization state. A retained translated module does
not prove that the driver rejected that module. Neither an application defect
