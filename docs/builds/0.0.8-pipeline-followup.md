## CPU output allocation

<!-- CodexAstraUlt: Remove an avoidable intermediate representation without
changing shader semantics, output order, fallbacks or native-title artifacts. -->
The existing CPU raster path produces a temporary array of all sixteen output
registers for every unique vertex, then immediately maps those rows into the
rasterizer's final vertices. Each intermediate row represents 256 bytes. The
candidate maps bounded eight-lane outputs directly into smaller packed vertices,
retaining the existing full-output API and geometry path where callers need all
registers. Existing optional-JIT handling is preserved; the candidate does not
enable it.

The packed non-geometry path no longer materializes a draw/chunk-sized
full-register vector. Register-output scratch is **2,048 bytes per executing
chunk**; final-output and control-flow allocations remain. The old mapping may
reuse its input vector allocation, and both paths still materialize register
values, so this is not a claim that all copies disappear or that a measured
amount of memory traffic was saved. The CPU input counter does not distinguish
full-width geometry work from the changed path.

The change does not make CPU shader execution free, change the PICA program,
skip draws, enable the optional shader JIT or claim measured handheld improvement.
Geometry processing, output defaults, partial batches and parallel ordering
must retain their existing behavior.

## First pipeline failure

<!-- CodexAstraUlt: Keep fixed diagnostic snapshots for the actual attempted
pipeline; generic error text and selected GPU policy cannot identify its shader. -->
Code 12 collapses pipeline failures to an error string. A pending translated
module can coexist with an attempt to use the generic interpreted shader;
fallback may then record a placed draw before runtime error checks stop the
session. The existing report cannot identify the initial rejecting pipeline.

The candidate exports `runtime.gpu.hardware.pipeline_failures`, with fixed
`foreground`, `background` and `cache_probe` slots retaining the first observed
failure in each context. Metadata identifies the attempted vertex/fragment stage,
SPIR-V byte count and FNV-1a fingerprint, static/specialization state, fragment
constants and Vulkan result. FNV-1a is a diagnostic fingerprint, not a cryptographic
identity. An expected compile-required cache miss is not a failure. Preserve
these snapshots instead of an unbounded history. This adds no shader dump,
monitor thread, per-draw log or continuous writer and does not suppress errors
or change rendering defaults/fallback policy.

The next failing report can identify a built-in generic module and reproducible
pipeline state, or show that a translated shader needs private investigation.
No raw private shader/source upload is requested before that distinction exists.
