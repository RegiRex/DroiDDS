## Meaning and remaining work

<!-- CodexAstraUlt: Keep synthetic execution, audit findings and unimplemented
runtime integration clearly separated in the release's evidence record. -->

CPU additions cover carry/shifts, Thumb-to-ARM, exactly representable finite VFP
arithmetic/conversion, and progress with a one-instruction slice. These do not
establish complete VFP/NaN/rounding behavior or kernel scheduling. Code checks
protect single-threaded immutable fixture text and both entry lookup paths;
CRO lifetime/remapping/concurrent mutation remain separate integration work.

The Vulkan test queries the selected Zakuro pin's required features/formats and
executes dynamic rendering, synchronization2, pushed texture/uniform descriptors,
D24S8 depth/stencil rejection, depth clamping and storage-image compute. Optional
dynamic blend/logic and statistics features are discovery only. These original
operations do not execute Zakuro's generic PICA shaders or qualify presentation,
cache behavior, sustained memory, gameplay or handheld performance.

The [New 3DS audit](../NEW3DS_AUDIT.md) reproduces incorrectly decoded mode/CPU/L2
fields and 64 MiB application limits despite 256 MiB physical RAM for synthetic
124/178 MiB requests. It also identifies region/configuration and scheduler risks.
The full title loader/kernel was not executed by that narrow harness. Fixes and
real loader/configuration tests are required during 0.0.5, before claiming
Xenoblade compatibility. No runtime patch is hidden in a shared Cargo cache.

## Reproduce and next device check

Use Rust 1.95.0, JDK 17, Android platform 35/build tools 35.0.0 and
NDK 27.3.13750724. The local host used GCC 14.2.0, Mesa 25.0.7/llvmpipe LLVM19.1.7,
Vulkan 1.4.305, loader/Khronos layer 1.4.309.

```bash
python3 tools/build_foundation.py --output out/foundation-new --jobs 2
python3 -m unittest discover -s tools/tests -v
VK_LAYER_ENABLES=VK_VALIDATION_FEATURE_ENABLE_SYNCHRONIZATION_VALIDATION_EXT \
python3 tools/build_vulkan_probe.py \
  --ndk "$ANDROID_HOME/ndk/27.3.13750724" \
  --vulkan-library "$VULKAN_LOADER" \
  --output out/vulkan-new --require-validation
python3 tools/build_android_probe.py \
  --sdk "$ANDROID_HOME" --java-home "$JAVA_HOME" \
  --output out/android-new --jobs 2 --prerelease
```

Follow [the Android instructions](../ANDROID_PROBE.md) for installing the APK and
its diagnostic signing transition. Run it on the Thor, wait for completion and
use **Save report**, even if it fails. Send that JSON; the owner's standing
instruction authorizes immediate validation/fixes and the next qualified roadmap
build through 0.1.0. A failed gate holds promotion.
