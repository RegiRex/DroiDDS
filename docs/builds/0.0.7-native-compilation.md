## Implemented behavior

<!-- CodexAstraUlt: Reuse the preparation contract and floating-point recipe,
while replacing automatic per-core scheduling for this bounded private route. -->
`tools/compile_private_title.py` and three helper modules implement
one Linux host compilation route. They use the existing compiler and Python
standard library, without importing a desktop frontend or adding dependencies.
No Android/runtime code or public app version changes.

The input helper revalidates the canonical preparation manifest, successful run
report, exact generated/identity inventory, raw descriptor/segment checks and
retained game snapshot. It copies only generated C/headers into private read-only
build inputs. The original preparation and game snapshot are unchanged.

The coordinator compiles one translation unit at a time, largest C source first,
with the existing optimized floating-point contract. Compiler driver/helper hashes,
target/version, tool code, exact recipe and all source/header identities bind the
compile plan. Clang implicit configuration is disabled. Per-object receipts are
published only after successful compilation, static object inspection and byte
checks. Interrupted partial objects remain private without a reusable receipt.
Resume rejects identity changes and reuses only revalidated objects.

Hard subprocess limits cover CPU, virtual address space and individual files;
the wall deadline supervises each compiler group. A finite batch deadline stops
additional compiler work, with bounded verification/reporting afterward. Compiler
commands run at reduced scheduling priority when available. Diagnostics retain
at most a 64 KiB tail per command. A separate attempt directory/report preserves
every prior attempt. One output lock prevents concurrent use of that build.

The retained build allowance includes copied sources and compilation output,
checked between commands. Metadata publication reserves its bytes and space for
the final bounded report. This is not a filesystem quota; failed compiler partials
may exceed the aggregate allowance before the next check. Details and exact
defaults are in [the local procedure](../PRIVATE_TITLE_COMPILATION.md).

Linking requires every verified object, adds RELRO/NOW/no-undefined and `-lm`, and
uses a response file for long/private paths. An additional original identity unit
exports the exact preparation and compile-contract SHA-256 strings. ELF audit
checks supported host type/architecture, bounded segments/sections, permissions,
dependencies, required export lookup, ABI/generation/count scalars and identity
strings. It checks relevant relocation destinations and both supported symbol
hash formats. It **never loads the library**. The final manifest binds the
audited library bytes and every object receipt.

System headers and runtime libraries are still host toolchain inputs, not a fully
hermetic/attested toolchain. Static audit does not validate relocated runtime
pointer-table semantics. Runtime manifest enforcement, executable-write/remap/CRO
freshness and actual native guest execution remain separate work. The generated
manifest explicitly records no library loading or guest execution.
