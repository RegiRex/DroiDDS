## Implemented behavior

<!-- CodexAstraUlt: Keep diagnostic storage fixed and optional, while making
the sampling boundary and limits of register/address evidence explicit. -->

- Capture the initial live CPU state, then one state every 65,521 dispatch
  steps. Retain the first 16 and latest 112 without overlap, with exact
  seen/omitted counts. Keep a separate final state even for a short run.
- Record live r0-r15, CPSR, steps, cycles, interpreted-instruction count,
  current thread slot/guest identity and scheduler flags. A missing current
  thread leaves the live registers unattributed.
- At stopping, decode the existing 64-entry recent dispatch-address history
  into addresses and ARM/Thumb mode. Keep this global history distinct from
  live r15 and current-thread metadata; a faulting dispatch can be included.
- Read no guest memory, instruction bytes or thread names, and enable no
  unbounded profiler. Store fixed-size scalar records and serialize once at
  stopping. No sampler storage is allocated when disabled.
- Validate activation, exact fields and scalar types, cadence, retention,
  counter order, terminal counters/PC and agreement with the scheduler's final
  snapshot when both traces are enabled. Hash the new sampler source in the
  coordinator's source identity.

Periodic samples precede the worker's per-frame HID update. That update may
change scheduler flags before the terminal sample at the same dispatch count;
the validator permits this while checking consistent CPU fields. The initial
live PC may be zero before the loader-queued main thread is first scheduled.
Idle dispatches can repeat old registers without executing another instruction.
Sampling can miss intermediate work; neither a changing register nor an
unchanged sampled state automatically proves correct progress or a deadlock.

Only the host title-tool crate and its coordinator change. No core, Android,
renderer, dependency or toolchain changes are included. The switch is independent
of `--trace-scheduler`, and both remain disabled by default. Trace wall time is
not a performance measurement.
