performance. Each case reaches an explicit SVC checkpoint and compares registers,
flags and its entire synthetic memory image. No game-derived fixture was used.

Four negative controls also passed: changed NaN-shaped integer register and memory
bits are rejected; a guest infinite loop is classified incomplete rather than
matching; a hung subprocess is stopped by the watchdog. Review identified an outer
cancellation bug that could orphan compiler children. The Rust/Python supervisors
were corrected and tested through the actual public CLI with a hanging fake
compiler and sleep descendant. Independent review also verified outer Python
SIGTERM cleanup. Interrupted runs fail and do not produce a passing fixture report.

## Limits and next step

This proves a small CPU integration baseline only. It does not exercise VFP
arithmetic, direct memory-page fast paths, CRO relocation/lifetime, executable
write invalidation, full HLE services, rendering, audio, Android or real titles.
The broad M0/M1 milestone gates are not all complete, and no Dark Moon fix or
Thor performance gain is claimed.

Next work is DDS-004/005 CPU transition/module coverage, the small A0 Android
loader/capability probe, and independent DDS-006 graphics test preparation. Keep
the working baseline and add minimized failing cases before optimizations.

Public output for this milestone is source, instructions, CI configuration and
evidence. No APK or compiled binary is attached. The
[notice inventory](../../THIRD_PARTY_NOTICES.md) retains the unresolved upstream
3dsrecomp copyright/notice provenance needed before linked binary redistribution.
