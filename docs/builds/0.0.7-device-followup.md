## Native live-condition regression

<!-- CodexAstraUlt: Exercise the real compiler, kernel and context save/restore;
do not promote a private raw flag difference based only on a mock ABI fixture. -->
A new original ARM guest creates a higher-priority peer. That peer sleeps until
cycle **43**, forcing a native budget return while **NZCV are live**. The actual
scheduler saves the main thread, runs the peer with changed flags, and restores
the main thread. Conditional execution and memory output agree with independent
expected values and the interpreter; both routes exit at cycle **207**.
The native route executes **57 generated instructions**, with zero interpreted
instructions or callbacks. The test checks exact saved PC/CPSR, final recorded
state and preservation of the original input. All **11 native-worker tests**,
formatting and strict Clippy pass.

The first test draft kept only N live while asserting full CPSR equality, so
omission of dead Z invalidated that oracle. The final guest consumes all NZCV
after restoration; no mask, expectation relaxation or production CPU change was
used. This covers one concrete scheduling case. It does not prove Dark Moon's
raw CPSR differences harmless, nor general native parity.
