DroidDS 0.0.2 is an **Android CPU diagnostic probe**, not a game emulator yet.
It tests loading ARM64 native libraries and running four original recompiled
ARM/Thumb CPU fixtures against interpreter and hand-calculated results.

Download **DroidDS-0.0.2-android-arm64.apk** below on an ARM64 Android 10 or newer
device. Open it and allow installation from the browser/file manager if Android
asks. Launch **DroidDS Probe**; the test starts automatically. Use **Run again** to repeat it. No game file is needed.
The app has no network, external-storage or Google-service permission.

The release build remains debuggable so local Codex can retrieve its one bounded
private report through ADB. It is installable normally without ADB's test-only
flag. This diagnostic app does not provide graphics, audio or retail game support;
a successful cross-build does not establish Thor execution or game performance.

**Signing:** this first public diagnostic build uses a newly generated CI probe
key. It cannot update an existing locally built probe signed by a different key.
If Android reports a signature conflict, do not let automation uninstall anything:
keep the existing app or explicitly decide whether to remove that diagnostic app
and its report before installing this one. No Uberhar key or package is used.
The CI private key is not uploaded or retained, so future probe releases may also
require an explicit reinstall if signed differently. A stable release-signing
identity will be established separately before normal application distribution.

`BUILD_REPORT.json` identifies the source commit, APK SHA256, signing-certificate
SHA256 and build scope. `SHA256SUMS` covers the three downloadable payload files.
`THIRD_PARTY_NOTICES.txt` is also embedded in the APK. The build pipeline runs the
Linux CPU foundation and Python validation gates before creating this prerelease.
