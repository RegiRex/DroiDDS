# DroiDDS 0.0.8 preview 4 — CPU vertex work

<!-- CodexAstraUlt: Ground this candidate in the completed code 13 CPU test

Code 13 reaches Dark Moon’s file-selection menu with Native execution and CPU
vertex shaders at **18.12% emulated speed**. No clear improvement is established.
CPU vertex work still consumes **34.80% of core time**, with other command
processing consuming another **28.45%**. Audio remains interrupted.

This candidate targets repeated CPU work:

- Resolve shader output semantics once per draw, then read the needed components
  directly instead of rebuilding a full packed register array for each vertex.
- Collect the final SIMD batch’s output directly instead of copying it into the
  branch-output list on every batch. Divergent branch outputs retain their order.
- Retain cached native-code verification when GPU guards change only pages
  outside admitted TEXT; overlapping guards and actual mapping changes still
  invalidate it, and backing/code protection remains checked.
- Add fixed CPU decode/placement timings and geometry-mode/parallel-vertex batch
  counts to identify remaining costs without per-vertex logs.

The changes preserve shader arithmetic, output defaults, geometry behavior and
draws. Automatic selection and error handling remain unchanged. The optional
shader JIT stays disabled. The existing preparation, completed title libraries,
imports, saves and owner signing identity remain reusable.
