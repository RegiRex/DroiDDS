## Candidate scope

<!-- CodexAstraUlt: Keep the unchanged automatic route distinct from the
explicit experimental comparison and preserve compiled-title compatibility. -->
This candidate:

- Removes an intermediate triangle-tuple allocation while preserving assembly
  order, topology, winding and all required draws.
- Offers Automatic, CPU and GPU vertex-shader selection before a session starts,
  keeping the existing Automatic default.
- Carries the selected policy through the runtime/JNI/frontend and reports bounded
  CPU batch/input/time, recorded GPU/placed draw counts and dynamic blend/logic
  flags, distinguishing policy from actual rendering paths.
- Reuses existing title preparation, compiled ARM64 objects and owner signing
  identity for the private update.

No Dark Moon speed improvement or successful GPU path on the Thor is established
by these notes. The Native/Interpreter guest CPU choice remains separate from
vertex shader location. The optional CPU shader JIT remains disabled.
