# DroiDDS 0.0.7 preview 3 — input and save corrections

<!-- CodexAstraUlt: Describe the implemented candidate and measured host scope;
this release policy is prepared before publication or device qualification. -->
This candidate preserves short button and touch presses while a title yields
between guest frames. Joystick direction and axes arrive together, and repeated
controller events no longer delay queued transitions. Pause still releases input
immediately.

Guest save operations now report real host errors, enforce read/write access,
and honor requested synchronization. Linked file handles remain usable after
the original handle closes. Authored guest tests cover write, commit, close and
reopen through native and interpreter execution. They do not establish retail
save compatibility or crash-atomic storage.

The included original test title is revision **v2**. Holding A at startup could
previously replace pending DSP initialization with a pitch change and silence
the tone. Its guest code now preserves those pending changes. Both CPU routes
and Vulkan retain exact image/audio oracles; historical v1 reports remain valid
under their original counters.

The public candidate contains only the authored test title. Dark Moon and other
owned games still need their own private ARM64 library and matching input. The
shared runtime corrections can use existing private preparation and compiled
title objects without regenerating them. No owned-game boot or handheld speed
improvement is established by these host tests.

<!-- CodexAstraUlt: The device check targets the corrected interactions and
keeps the earlier preview's human observations separate from this candidate. -->
When this candidate is published, install
`DroiDDS-0.0.7-preview.3-original-android-arm64.apk` and open **DroiDDS**.

1. Load the included test, select **Native**, and play. Check both guest images
   and a steady tone. Hold A immediately on startup and confirm sound continues.
2. Try short D-pad/A presses, touch the lower guest image, and reverse joystick
   direction diagonally. Check that the marker responds without stale directions.
3. Pause/resume, switch apps and return, then stop and start again.
4. Export the title report and include any visible or audible problem.

Both guest views still use one physical display. The Thor's separate lower
screen is not supported. Rendering still uses Vulkan with screen readback and
Bitmap/Canvas presentation. Native execution currently requires 4 KiB host pages;
16 KiB library alignment alone does not qualify 16 KiB devices.
