The candidate projects completed CPU shader output directly into the rasterizer's
21-component vertices, removing an intermediate full-register output copy. The
eight-lane output scratch shrinks from **2,048 to 672 bytes**; full shader/fork
state remains. Shader arithmetic, geometry, input ordering and draws retain their
existing behavior. Thirty paired authored host benchmark cases measured
**3.5–32.5% lower component time**, which does not establish handheld or whole-game
improvement. The optional shader JIT stays disabled.
