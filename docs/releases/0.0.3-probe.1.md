DroidDS 0.0.3 keeps the four CPU tests that passed in the owner's Thor report and
adds a **Vulkan rendering test** plus **Save report**.

Download **DroidDS-0.0.3-android-arm64.apk** on an ARM64 Android 10 or newer device.
Launch **DroidDS Probe** and let the tests finish. Then tap **Save report** and
choose Downloads or another location; the exported JSON can be attached to the
development chat without ADB. A cancelled or unavailable document picker does not
change the test result or remove the private report.

The Vulkan test creates a real graphics pipeline and checks every pixel in three
16×16 patterns. It repeats those checks across three new Vulkan devices and
resource sets, and confirms that deliberately corrupted pixels are rejected.
The report records Android/model and Vulkan driver information. A pass requires
both CPU and Vulkan success; missing Vulkan support is reported as a failure.

This is an offscreen diagnostic. It does not display or emulate a 3DS game, test
PICA shader behavior, or measure gameplay performance. The release pipeline runs
the shared graphics code on software Vulkan with Khronos validation; the Thor
GPU and document-picker behavior still require a device run.

**Installing over 0.0.2:** the first diagnostic release's private signing key was
not retained. Android may reject an update because this build has a different
signer. If that happens, keep any report you want, then manually uninstall only
**DroidDS Probe** before installing 0.0.3. Removing that diagnostic app deletes its
private report. The installer/ADB runner never performs that removal automatically.
Uberhar uses a separate package and is unaffected. Stable product signing remains
separate work; this probe's private CI key is not published or retained.

The APK needs no network, broad storage, Google or vendor-service permission.
It retains one bounded private report; export writes only the document you select.
`BUILD_REPORT.json`, `SHA256SUMS` and `THIRD_PARTY_NOTICES.txt` accompany the APK.
The package remains debuggable for local ADB report collection.
