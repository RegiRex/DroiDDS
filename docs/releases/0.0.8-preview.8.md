**Candidate under development; correctness, benchmarks, packaging and
publication remain pending.** Code 17 reached Dark Moon's file-selection menu
at **18.66% emulated speed**, essentially unchanged from code 16. Its tiled
optimization never engaged. Hardware display-transfer attempts consumed
**23.980 seconds**, and texture synchronization consumed **5.906 seconds**.
The owner reports severe audible clipping alongside **1,531 underruns**;
waveform clipping is not measured.

The proposed immutable **NativeReadback** mode matches the title frontend's
native-resolution byte consumer. It omits otherwise unused upright/screen
captures for accepted linear transfers while retaining native capture,
synchronization and submission. Default scaled/direct consumers keep their
existing behavior. Fixed phase/readback counters record capture and timing
totals without growing traces; new device measurements remain pending. No draw
skipping, relaxed guest-memory visibility or handheld performance gain is claimed.

[native Android architecture review](https://github.com/RegiRex/DroiDDS/blob/main/docs/NATIVE_ANDROID_DIRECTION.md)

the existing AOT compiler, accurate fallback and compatible title libraries.

93.32% of code 17's measured core time. This candidate is a bounded first step,
not a full graphics replacement or a playable-beta qualification.
